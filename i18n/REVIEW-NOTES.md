## Institutions and names
- Somali Future Council = Golaha Mustaqbalka Soomaaliyeed; Somali Salvation Forum = Madasha Samatabixinta Soomaaliyeed
- NIEBC = Guddiga Madaxa-bannaan ee Doorashooyinka iyo Xuduudaha Qaranka; JSP = Xisbiga Caddaaladda iyo Wadajirka
- Northeast State = Waqooyi Bari; Paris Club = Naadiga Paris; Operation Black Lion = Hawlgalka Libaaxa Madow
- State minister = wasiiru dowlaad / Wasiiru Dowlaha (two spellings are in use: pick one)
- Name spellings: Axmed Macallin Fiqi, Abuukar Daahir Cismaan, Biixi Iimaan Cige, Lafta-gareen, Kheyre

## Technical terms
- caretaker = xil-gaarsiin; constitutional vacuum = firaaq dastuuri ah
- HIPC Completion / Decision Point = Barta Dhammaystirka / Go'aanka; staff-level agreement = heshiis heer shaqaale
- current account = xisaabta socota; nominal GDP = GDP-da magaca ah; present value = qiimaha hadda
- cost / profit petroleum = batroolka kharashka / batroolka faa'iidada; production-sharing agreement = heshiis wadaag wax soo saar
- EEZ = Aagga Dhaqaale ee Gaarka ah; TPS = Xaaladda Ilaalinta Ku-meel-gaarka ah; assessed contributions = wax ku biirinta qasabka ah
- IPC phases: Xaalad Xasaradeed (Crisis), Xaalad Degdeg ah (Emergency), Masiibo (Catastrophe)
- Left in English: "seismic", "Early Cretaceous", "Extended Credit Facility"
